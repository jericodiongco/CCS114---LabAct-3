About This Project

This landing page was built as part of Midterm Laboratory 3 for CCS114 – Web Technologies at the University of Cabuyao. It demonstrates the use of HTML5 semantic structure, CSS3 custom styling, and Bootstrap's grid system and components to build a responsive, modern-looking two-page website.

  • Fully responsive design
  • Bootstrap grid, navbar, cards, forms, and alerts
  • Custom CSS3 colors, shadows, and hover effects
